01 / THE IDEA

什麼是遊戲式學習

遊戲式學習把完整遊戲作為學習活動，讓知識與技能成為完成目標所需的能力。它不同於在既有課程中加入積分或徽章的遊戲化設計。玩家透過行動、觀察結果、修正想法，在遊玩中練習並建立理解。

◎

玩法承載學習

學生要運用正在學的概念，才能完成任務。學習不是遊戲之外附加的一張測驗。

↗

清楚的結果、提示和重試機會，幫助學生理解策略為何有效，並嘗試更好的方法。

02 / PLAYABLE MECHANICS

十種機制，十個可玩範例

先玩一會，再想想要練習什麼。以下範例來自 Phaser 官方範例庫，遊戲畫面直接嵌在卡片裡。

01目標與收集

讓任務變得看得見

把學習拆成可完成的小目標。每次找到線索或收集物件，都讓學生看見自己離目標更近。

適合練習
觀察、辨識、依條件蒐集資訊

PHASER EXAMPLE

First Game Part 10

先點選遊戲畫面，再用方向鍵移動，收集星星並躲避炸彈

02放置成長與累積

離開一會兒，回來收穫新驚喜

種下蘑菇後，森林會隨時間慢慢成長。安排種植順序、等待成熟，再收集露珠與解鎖新種類，讓長期目標藏在療癒的日常裡。

適合練習
時間概念、資源分配、長期規劃

PHASER EXAMPLE

苔光小徑｜蘑菇放置遊戲

選種子、種下蘑菇，等待生長並收集露珠

03漸進挑戰

難度跟著熟練度前進

先讓學生掌握基本規則，再逐步提高速度或精度要求。挑戰要讓人需要專注，也要保留成功的可能。

適合練習
精熟技能、穩定操作、逐步增加難度

PHASER EXAMPLE

Stacker

按下空白鍵或點擊，抓準時機放下方塊

04選擇與後果

每個決定都帶來不同結果

讓學生在安全的情境裡評估風險、選擇行動，再根據結果檢視原先的判斷。

適合練習
判斷證據、衡量風險、說明決策理由

PHASER EXAMPLE

Bank Panic

觀察門口出現的人物，再決定是否射擊

05記憶提取

從記憶中找回關聯

翻牌時先提取記憶，再用配對結果確認線索。可把卡片換成詞語和定義、符號和名稱或問題和答案。

適合練習
詞彙、符號、概念配對與間隔複習

PHASER EXAMPLE

Card Memory

翻開卡片，試著找出相同圖案

06模式辨識

發現相同與不同之處

學生要比較圖案、辨認特徵並找出相同項目。改變分類規則，就能練習新的概念線索。

適合練習
分類、觀察特徵、找出規律

PHASER EXAMPLE

Emoji Match

在限時內找出成對的表情圖案

07空間推理

安排順序，拼出整體

移動局部拼圖片時，學生要想像位置變化和下一步的影響，再逐步建立整體圖像。

適合練習
方位、順序、地圖和視覺組織

PHASER EXAMPLE

Sliding Puzzle

移動相鄰拼圖片，還原完整圖像

08邏輯推理

根據線索提出假設

玩家根據數字線索推斷安全位置。把推理過程說出來，能讓猜測變成可檢查的想法。

適合練習
條件推理、機率概念、解釋證據

PHASER EXAMPLE

Minesweeper

左鍵開格，右鍵標記你推測的地雷

09有限步數規劃

在限制中比較策略

步數有限時，每次選色都要考慮它能擴大的範圍。學生可以比較路徑，選擇更有效率的策略。

適合練習
預算、資源分配、策略規劃

PHASER EXAMPLE

Flood Fill

選擇顏色擴展區域，留意剩餘步數

10因果預測

從結果理解規則

預測球的方向，調整擋板位置，再觀察碰撞結果。這種循環很適合練習因果關係和假設驗證。

適合練習
角度、速度、因果關係與反覆驗證

PHASER EXAMPLE

Breakout

移動滑鼠控制擋板，點擊發球

03 / DESIGN NOTES

讓機制真的支持學習

同一種機制可以帶來樂趣，也可以帶來挫折。教學目標、難度和回饋需要一起設計。

先問要學會什麼

先寫下希望學生能做出的行動，再挑選能支持這個行動的玩法。

讓回饋提供線索

除了告訴學生對或錯，也指出他們可以檢查的概念和下一步。

重視過程與反思

讓學生說明策略、比較結果，並把遊戲中的理解帶回課堂情境。
